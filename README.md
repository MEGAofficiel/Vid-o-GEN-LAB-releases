# Vidéo Lab — téléchargements

Ce dépôt ne contient que les **versions publiées de l'application de bureau Vidéo Lab** (Windows). Le code source est développé dans un dépôt privé.

## Télécharger

La dernière version est toujours ici : **[Releases → latest](https://github.com/MEGAofficiel/Vid-o-GEN-LAB-releases/releases/latest)**. Téléchargez le fichier `VideoLab-Setup-<version>.exe` et lancez-le.

Windows peut afficher un avertissement SmartScreen, car l'installeur n'est pas encore signé : choisissez « Informations complémentaires » puis « Exécuter quand même ».

## Mises à jour

Une fois installée, l'application vérifie ce dépôt à chaque démarrage, télécharge la nouvelle version en arrière-plan et l'installe à la fermeture. Aucune action n'est nécessaire.

## Signaler un problème

Ouvrez une *issue* sur ce dépôt en indiquant la version (menu Paramètres) et ce qui s'est passé.
